# Taiga IoT Docs

Docusaurus documentation site for Taiga IoT products and software.

- **Live (planned):** http://95.183.13.164:3002/
- **Repo:** https://github.com/b0ka-k/taiga-iot-docs

## Local development

Requires Node.js 20+.

```bash
npm install
npm start
```

## Production build

```bash
npm run build
npm run serve
```

## Docker (server)

See [DEPLOY.md](./DEPLOY.md).

```bash
docker compose up -d --build
```

Site is served on port **3002**.

## Content

Edit files under `docs/`. Sidebar is autogenerated from the folder structure.
